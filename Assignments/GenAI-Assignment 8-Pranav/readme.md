## Overview-
This repository contains a Python Jupyter Notebook assignment focused on practicing and implementing various application for Streamlit. Each file in the folder corresponds to a distinct task or problem, designed to test modular programming, logic building, and function design in Python.

## How to run-
Open your terminal or command prompt, navigate to the folder containing the .py, and run the file using **streamlit run filename.py**
Make sure to test your functions with the provided test cases or add your own custom test cases.
Running a task cell will execute the function and display test results or expected outputs directly below the cell.
