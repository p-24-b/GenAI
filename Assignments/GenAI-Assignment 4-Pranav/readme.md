## Overview-
This repository contains a Python Jupyter Notebook assignment focused on practicing and implementing various Python file handling. Each cell in the notebook corresponds to a distinct task or problem, designed to test modular programming, logic building, and function design in Python.

## How to run-
Open your terminal or command prompt, navigate to the folder containing the .ipynb file, and start Jupyter.
Run the code cells sequentially by pressing Shift + Enter or by clicking the Run button in the toolbar.
Make sure to test your functions with the provided test cases or add your own custom test cases.
Running a task cell will execute the function and display test results or expected outputs directly below the cell.
